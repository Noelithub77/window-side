The Rust `ws` binary provides a native black and teal setup/status window and
explicit CLI commands for the same Windows installation.

This archive targets Arch Linux on x86_64. Extract it and run `./install.sh`.
The installer only installs the app; opening `ws` previews the machine setup
before administrator approval. Read the included README before configuring a
real Windows partition.

This is a prerelease. Fresh Windows provisioning, transition from SATA to
VirtIO, same-drive Windows/Linux storage and native Windows boot compatibility
are not yet verified end to end. A draft build is not a stable release.
